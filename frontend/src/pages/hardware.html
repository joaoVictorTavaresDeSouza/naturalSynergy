Componentes

O que faz parte do protótipo

Estas são as peças previstas para montar o sistema vestível e a função de cada uma.

  • ESP32

    Processamento e controle do sistema.

  • MPU6050

    Leitura de aceleração e rotação.

  • MAX30102

    Leitura de sinais ópticos relacionados à frequência cardíaca.

  • SIM800L

    Comunicação celular e envio de SMS.

  • Bateria LiPo

    Alimentação elétrica do protótipo.

  • Impressão 3D

    Estrutura que abriga os componentes e permite usar o sistema no corpo.

Como as partes trabalham juntas

  1. Os sensores acompanham sinais

    O MPU6050 registra movimentos, enquanto o MAX30102 lê sinais ópticos relacionados à frequência cardíaca.

  2. O ESP32 coordena o sistema

    O microcontrolador recebe as informações dos sensores e organiza o funcionamento do protótipo.

  3. O alerta pode ser enviado

    Com o botão de emergência, a proposta é usar o SIM800L para enviar um SMS pela rede celular.

Natural Synergy

Sistema IoT vestível para detecção de crises epilépticas e alerta de emergência. Projeto acadêmico apresentado no SIPIC (Simpósio de Pré-Iniciação Científica) do Colégio UNASP-SP.
